First release under the new app id `com.binaryforge.serafim`. If you have an older Serafim installed, uninstall it once and install this APK; future updates install from inside the app.

**New**
- Group chats with roles, rules, and a privacy setting for who can add you
- Voice messages (hold to record, slide to cancel, slide up to lock)
- Stickers, and GIFs straight from your keyboard
- Link previews and tappable links
- Chat backgrounds, per chat or for all chats
- Full-screen profile photos
- Notifications page, official SERAFIM chat, bios, copyable UID
- See other people's friends and followers (unless their profile is locked)
- In-app updates from this page
